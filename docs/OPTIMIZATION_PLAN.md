# PE 阵列与非 MAC 优化方案

日期：2026-11-08。依据：[飞书竞赛要求](https://xcnjdg7296m8.feishu.cn/wiki/YLkowzJAAifUCGkwOtpcVST1nnc)，本次重新读取了阵列扩展、非 MAC、系统优化和验收条款。

2026-11-10 更新：10 种阵列与 6 种短名单后端均已完成同条件映射。第一阶段工程主候选为 **8×16×4 + 128 个原 SRAM + 共享一套 FP32**，其依据、当前源文件哈希和验收缺口见 `native/optimization/第一阶段工程选型.md`。当前 C 库的 7/12/67 命令 RV32 回归均通过，第一阶段模块工程验收完成。第二阶段固定首张图片的真实 RV32+全部八引擎 VCS 完整推理已启动；最终整机配置仍待精度、完整 SoC 面积/总周期和 ADP 测量。下文早期整图证据均保留原验证范围，不扩大到新代码。

## 选择标准

目标为同一 SoC、时钟和外部内存条件下的最小端到端 ADP。新增硬件须实际参与 Swin 推理，面积包含新增存储、搬运、控制和计算逻辑。不能用模块数量、理论峰值或小范围周期替代整图结果。

本轮先比较有限、可复现的候选，再确定最终实现。没有证据支持“任意硬件设计中的全局最优”，因此最终结论将限定为经过同条件验证的候选集合。当前已收齐阵列及后端模块映射并通过第一阶段 C 调度回归，尚未宣布最终 SoC 最优配置，也未替换已通过任务一验证的日常工程。

## 实际瓶颈

- 原 16×16、每 PE 四通道阵列，对中心化仿射 INT8 使用四次平面乘积；全图为 17941440 次 PE 计算、1148252160 次结果读取、181690705 次配置写入。
- 真实 RV32 + 完整 SoC RTL 的非 MAC 微基准中，量化约 3717 周期/元素、反量化约 1358、Add 约 1148、Erf 约 19231、LayerNorm 约 4310、Softmax 约 17260。这里只测了代表性内核，没有据此声称整图耗时。
- Swin 没有 ReLU。重点应是 GELU、量化/DQ、LayerNorm、Softmax 和窗口/移位重排，而非增加模型未使用的模块。
- 原整机综合面积约 3189674，其中 256 个 SRAM 宏约 1805273。直接复制阵列会明显增加面积，必须同时解决带宽和控制问题。

|其余浮点|一套共享 FP32 向量运算/归约|三套独立 FP32、RISC-V 软浮点；并行多通道留待实际热点支持后研究|三种几何的共享资源对照已测；当前串行调度下逐命令周期一致，面积较小|

## 实现顺序

1. 冻结原工程、模型和当前软件基线；记录算子、流量、周期与哈希。已完成。
2. 独立验证原生 PE、流水阵列、查表变换和共享 FP32；扫描完整阵列配置。单元、软件变换和全部 10 种阵列面积扫描已完成。
3. 实现视图化和统一数据布局，在全部 20 图上证明相对于原 C 基线没有新增误差。连续视图及融合后流式布局已完成上述验证。
4. 实现共同的 AXI DMA、步长地址生成、片上累加和 LUT 缓存；接入阵列与非 MAC 单元。八引擎的三几何 RV32 交错和六个后端映射已完成。新增 Slice/Concat/AvgPool 借助既有 DMA/向量组合，主机逐位比较通过，实际 RV32 测试运行中；当前 C 库的两项回归已通过。
5. 接入隔离的优化 SoC 与 RISC-V 调度程序，使用明确的 64 MiB 外部 AXI RAM。新增 LUT 常量约 4.70 MB；三种候选的最新整图固件均为 52592 字节，只编译、未执行模型。
6. 跑完整 Swin 推理，记录 MAC、非 MAC、搬运、等待及最终输出周期；对短名单进行整机综合、STA 和必要的门级复验。
7. 在精度、时序、内存条件满足后，按实测 `总面积 × 总周期 × 统一时钟周期` 排名，确定候选中的最优解，最后更新日常 GUI 默认入口并交付优化前后报告。
