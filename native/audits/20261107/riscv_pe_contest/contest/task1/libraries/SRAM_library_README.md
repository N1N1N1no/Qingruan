# SRAM 输入电容工程候选库 v011

新库：`SRAM_cap_v011.lib`。仅供工程评估，不是完整自表征库或 signoff 库。

## 本次实际改动

在原 TT/1V/25C、16x8 的 72 点读时序工程库上，仅替换五处输入电容属性，覆盖 15 个脚。总线电容为每位数值，不是整条总线的总和。

| 输入脚 | 本次电容 fF | Liberty 数值 pF |
|---|---:|---:|
| clk | 0.563401 | 0.000563401 |
| addr_in[3:0]，每位 | 1.206596 | 0.001206596 |
| wd_in[7:0]，每位 | 1.206594 | 0.001206594 |
| ce_in、we_in，各脚 | 1.206596 | 0.001206596 |

数据来自 15 脚 × 两步长（1ps/0.5ps）的 30 次仿真报告，各次包含上升和下降。固定周围状态、单输入翻转、输入 10–90% slew=5ps。每脚取两步长、两个方向中最大观测值，向上舍入到 0.000001fF；这只是已测条件下的工程取值，不是所有状态/slew 的上界。小数位数不代表物理测量精度。

证据归档已核对：30 个结果均完成且指标通过；每脚步长变化不超过 1%，报告窗口变化不超过 1%。本地验证了归档、报告引用、deck/info/log/exit 的 SHA256；归档没有电容原始波形，未在本地重新积分电容波形。来源条件和每脚候选值完整记录于 manifest。

## 明确保留的内容

- 原库读时序表、cell/library 名称、接口和所有非电容属性逐字符不变（除了开头说明）。
- setup/hold、internal_power、leakage、面积仍来自旧模板，没有宣称为本次实测。
- 地址 `max_transition=0.04ns` 未改变。A0 宽松点慢输入测试通过，不等于已证明可以放宽该限制。
- 泄漏试跑仅覆盖禁用态固定图案；最新 CLK1 1.25ps 复测截图显示通过，但该点原始工件不在本包。本包不把局部状态泄漏改填为通用 cell_leakage_power，也不修改原来失败的粗步长结果。
- manifest 中 `opensta.passed=null` 表示本地没有 OpenSTA，不能沿用父库的读库通过记录。运行下面检查只在终端报告本次结果，不修改 manifest。

本次输入电容高于旧模板约 0.2091fF，替换后陈需要重评估驱动、扇出与地址 slew；之前约 67ps/260ps 的集成数值不能保证不变。

## 服务器只读检查，不启动 Xyce

在本目录运行：

```bash
sha256sum -c SHA256SUMS &&
python -B check.py check --root "$PWD" --opensta sta
```

预期：`structural_checks_passed: true`、`covered_input_pins: 15`、`opensta.passed: true`。如果 sta 不存在、读库报错或校验失败，命令返回非零，停止使用此候选库，不应手改检查或阈值。通过读库仅表示语法/读取检查通过，不等于仿真、完整表征或 signoff。

`base.lib`、`base.manifest.json` 仅作旧版只读对照，不是本次交付的新库。`evidence.tar.gz` 是原封不动的用户证据包。`check.py` 可以独立使用，仅依赖 Python 标准库；`SHA256SUMS` 用于传输校验，不是数字签名。

本地自动测试：新增导出/防篡改/边界测试 10 项；OpenSTA 分支测试使用模拟返回值，不代表本地执行过 OpenSTA。
