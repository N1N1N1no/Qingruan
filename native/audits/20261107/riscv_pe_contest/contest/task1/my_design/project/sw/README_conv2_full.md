# 完整第二层：conv2_full.c

这个程序把上一阶段**真实 CPU 得到的第一层池化输出**作为输入，让原来的 RISC-V＋PE 电路计算第二层。标准答案只放在测试环境中，不放进 C 程序。

```text
第一层实际输出：32 张 64×64 数字图
    → 第二层 3×3 卷积：64 张 62×62 数字图
    → CPU 执行 ReLU 和 Q24 量化
    → 每 2×2 个数取最大值
    → 第二层输出：64 张 31×31 数字图，共 61504 字节
```

程序支持计算整层，也支持 `C2F_TILE_START`、`C2F_TILE_COUNT` 指定连续范围，方便先检查边界，再分段覆盖整层。多次仿真的结果可以合并检查完整范围，但这不代表一次 CPU 启动已经串起两个完整层；也不能把并行仿真时间当作模型推理时间。

## 一个 tile 是什么

这里的 tile 是“一个池化位置、16 个输出通道”。一个池化位置需要左上、右上、左下、右下四个卷积值，正好由 PE 的四路乘法器处理。PE 的 16 列各负责一个输出通道。

64 个输出通道分成四组，每组有 `31×31=961` 个池化位置，因此整层共有 `4×961=3844` 个 tile。编号规则为：

```text
tile = 通道组 × 961 + 池化行 × 31 + 池化列
```

## 288 项为什么分 18 批

一个卷积值需要 `32 个输入通道 × 3×3 = 288` 项乘加。PE 只有 16 行，因此一次处理 16 项，一共 `288÷16=18` 批。CPU 将实际读回的 18 个部分和累加，再执行量化、池化；偏置在累加开始时只加入一次。

程序使用 `int32_t` 累加。生成器提供最大偏置绝对值，编译时检查：最大偏置绝对值加上 `288×127×127` 仍不超过有符号 32 位范围。这个界限也覆盖中途任何一批的累加结果。

## 为什么一次处理最多 32 个位置

如果每算一个 tile 都重写 18 批权重，会产生许多重复操作。现在把同一组通道的最多 32 个相邻位置合成一个 block：

1. 给这个 block 的每个位置设置初始偏置。
2. 写入第 1 批权重，依次计算这最多 32 个位置。
3. 换第 2 批权重，再计算同样的位置，继续累加。
4. 完成全部 18 批后，量化、池化，保存实际输出。
5. 开始下一个 block。遇到通道组边界时，提前结束当前 block。

这样每批权重可以重复使用最多 32 次。所有权重都写入 PE 的 SRAM 地址 0；不会要求现有 16 个地址同时容纳 18 批权重。

每次更新输入后，程序保留 MMIO 屏障，并等待 64 条明确的 `nop`，再读实际 PE 输出。独立监视器检查每一次返回值，不能只凭等待时间判断结果正确。

## 内存里放什么

| 内容 | 大小 |
|---|---:|
| 完整第一层实际输出 | 131072 字节 |
| 第二层权重 | 18432 字节 |
| 64 个偏置 | 256 字节 |
| 完整第二层池化输出 | 61504 字节 |
| 最多 32 个位置的累加缓冲 | 8192 字节 |

此外还有程序、进度变量和栈。固件继续使用原来的 256 KiB RAM 和链接脚本，链接时检查是否与栈重叠，不扩大电路中的 RAM。没有保存整层 32 位卷积中间结果。

`conv2_full_output` 是实际输出数组，按 CHW 顺序排列：先存第 0 个通道的 31×31 个字节，再存第 1 个通道，以此类推。`conv2_full_progress` 记录阶段、最后完成的 tile、完成数量和输出字节数，供测试环境观察。

## 怎样知道程序真的算对

独立测试环境检查实际接受的 MMIO 写入、PE 返回的部分和和 CPU 写入 RAM 的池化字节。部分和的顺序为“block → 批次 → block 内位置 → 列 → 路”。

每次启动有 66 次初始化写入。含 `n` 个 tile 的 block 有 `18×(80+16×n)` 次 PE 写入和 `18×n×64` 次 PE 读取。完整第二层需要检查 4428288 个实际 PE 部分和和 61504 个实际池化字节。

可用以下宏故意制造错误，检查监视器是否会拒绝错误结果：

| 宏 | 故意改错的位置 |
|---|---|
| `C2F_INJECT_WEIGHT_ERROR=1` | 第一个 block、指定项的第一个权重字节最低位 |
| `C2F_INJECT_INPUT_ERROR=1` | 第一个 tile、指定项的左上输入字节最低位 |
| `C2F_INJECT_POOL_ERROR=1` | 第一个 tile、第一个输出通道的池化结果最低位 |

输入与权重负控使用生成器选择的 `C2F_FAULT_TERM`，使对应输入和权重非零。正常程序不启用这些宏。
