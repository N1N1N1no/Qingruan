# 原始 RTL 仿真编译选项核对

2026-11-11 更新：VCS 文档中的 `+rad` 已完成原 CPU＋PE 三组计算、预设错误、两轮完整模型前缀测试及四次同核心复测，独立审核均通过。固定核心的两轮观察速度比分别 1.053873 和 1.065874，未达到内部两轮均至少 1.15 的宿主仿真采用门槛，未采用新的完整推理运行方式。

本次只使用本机已有源码、固件、镜像、参考和 VCS 帮助，不下载附件。原始完整 VCS、Verilator、新流水首图、门级和其余 19 图的运行继续保留。

三组计算覆盖原 Conv、动态 Attention 和跨 K=128 的静态计算，共 75 个 CPU 输出、3705 次 MMIO 写、5376 次读。新编译的正常与预设错误事务轨迹分别与原记录逐字节一致，周期相同。正常测试为 3472297 CPU 周期。预设错误仍在原监视器的相同位置、时刻以相同算术差异终止；此处是原监视器检错，不能表述为 CPU 自检证明。

第一次审核把预设错误应有的 Fatal 误判为异常，已保留失败和诊断。第二版只修正该审核规则，复用已经逐字节一致的基准轨迹。未修改原 HDL、固件和参考，也未覆盖原完整仿真的可执行文件。

本机 `-full64 -help` 明确记录 `+rad`；原完整模型编译本来已关闭调试。本次完整模型编译的变化限于 `+rad`、隔离输出目录及兼容对象路径。微测试另沿用已验证的适配：移除未启用的 WAVE 分支、关闭调试。

有限实验比较同一 2000 万 CPU 周期前缀的 385 个节点事件、绝对 CPU 周期及报告。两轮均逐项一致：

|顺序|原编译宿主耗时/秒|`+rad`宿主耗时/秒|观察速度比|
|---|---:|---:|---:|
|原编译→`+rad`|538.533437|411.963809|1.307235|
|`+rad`→原编译|436.102541|395.279464|1.103276|

仅当第一轮观察到至少 15% 的宿主机仿真加速，才反序再测一轮；两轮均达到该门槛才进入另行采用审核。这个阈值是内部工程门槛，不是飞书性能标准。本次未达到两轮门槛，未采用。独立审核实际核对编译参数和唯一未启用 WAVE 分支适配、正常/预设错误事务、四次前缀事件/报告及全部哈希，476 项源/工件哈希重验通过，原模板 38 项运行文件保持不变。其结论限于这些有限测试，不证明完整模型或硬件性能。

调度条件核对：本机 i7-14650HX 的允许 CPU 中有 3.7/5.0/5.2GHz 不同最高频率组，上表两侧测试没有固定同一核心，首轮没有历史核心调度记录。因此，上述速度比只作为观察值，不能排除核心调度影响，也不能归因为 `+rad` 的确定收益。后续同核心对照单独记录；当前采集不补称首轮历史调度证据。

同一核心有限队列验证已有实验真实父进程的 PID、启动时刻和命令，等其正常结束后先完成独立审核，再执行四次前缀对照。逻辑核心为 22，无 SMT 同胞；每次进程的 21～22 次亲和性观察均为 `[22]`，CPU 时间/墙钟时间均约 0.9994～0.9996。已有进程亲和性未修改，核心独占和频率固定均未声明。
